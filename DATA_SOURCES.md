# Data Sources

This repository does not host large external datasets.  
All datasets used in this study are publicly available from their original repositories.

---

## Genome-scale metabolic model

Human-GEM (Human1)

Repository  
https://github.com/SysBioChalmers/Human-GEM

Reference  
Robinson JL et al.  
An atlas of human metabolism.  
Science Signaling (2020)

File used in this repository:

Human-GEM.xml

This file provides the stoichiometric matrix and gene–protein–reaction associations used to construct the metabolite operator.

Repository  
Metabolomics Workbench

Study ID  
ST003506

Link

Serum metabolomics dataset from breast cancer-related lymphedema patients and controls.

File included in this repository:

Table/ST003506_AN005756.txt
