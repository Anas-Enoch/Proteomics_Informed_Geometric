# Figure Provenance

Every manuscript figure traced through the repository: analysis script →
input data → intermediate/raw CSV → summary CSV → plotting script → output PDF.
Each entry was verified by tracing actual files and `grep`-ing read/write calls,
not by assumption. **Status** is *Conceptual* (workflow diagram, no numerical
data) or *Computed* (quantitative, must derive from CSVs). A broken link is
marked **FAIL**.

                              ↓

(+0.152, +0.335, +0.388, +0.499) to 3 decimals; `advantage = random_mean −
